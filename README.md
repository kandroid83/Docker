## Задание 3

### 1. Воспользуйтесь docker help или google, чтобы узнать как подключиться к стандартному потоку ввода/вывода/ошибок контейнера "custom-nginx-t2".
### 2. Подключитесь к контейнеру и нажмите комбинацию Ctrl-C.
### 3. Выполните docker ps -a и объясните своими словами почему контейнер остановился.
Контейнер остановился, потому что главный процесс (nginx) получил сигнал остановки (Ctrl+C) и завершил свою работу. 
Без работающих процессов контейнер не может существовать — он автоматически переходит в статус Exited. (завершил работу)
